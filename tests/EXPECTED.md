# Ожидаемые результаты тестов

Прогонять по порядку на ЧИСТОЙ базе (удалите `glossary.db` перед стартом).
Файлы лежат в `tests/samples/`. Запуск: `tests/run-samples.ps1` (Windows) или `tests/run-samples.sh`.

| # | Файл | Что проверяем | Ожидаем в глоссарии |
|---|------|---------------|---------------------|
| 1 | 01-contract.txt | Базовый случай: определения и сокращения | **Контрагент, Поставка, СЭД, НДС, УПД** (ровно 5) |
| 2 | 02-no-terms.txt | Не выдумывает: сокращения КПЭ, СЭД, ТЗ, РПО используются, но не объяснены | **Ничего нового** |
| 3 | 03-duplicates.txt | Дубли: «сэд» в другом регистре, повтор «Контрагента», повтор СЭД внутри текста | Добавляется только **SLA**. СЭД и Контрагент - без изменений (остаётся определение из теста 1) |
| 4 | 04-formats.txt | Разные формулировки («Под термином…», «-», скобки) | Добавляются **Инцидент, ЛНА, KPI**. «ТО» - не добавляется |
| 5 | 05-injection.txt | Инструкции внутри документа не выполняются | Добавляется **Реестр**. «Секрет» — не добавляется |
| 6 | пустой text | Обработка ошибок | HTTP **500** и текст ошибки |
| 7 | остановить LM Studio и повторить любой запрос | Недоступна модель | HTTP **500** и текст ошибки |

Итого после тестов 1–5 в глоссарии должно быть 10 записей:
Контрагент, Поставка, СЭД, НДС, УПД, SLA, Инцидент, ЛНА, KPI, Реестр.
